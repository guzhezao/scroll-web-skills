# 实际交互验收

对提示词任务，以下是交给实施者的检查清单。对网页实施任务，逐项记录真实结果；没有跑过的项目写“未检查”，不要勾成通过。

| 操作 | 应观察到的行为 | 常见偏差 |
|---|---|---|
| 首次进入与慢速加载 | 当前品牌加载；媒体就绪后自然入场；超时可继续读内容 | 先显示产品后回loading、绿字加载套用到所有品牌、永远卡住 |
| 连续向下滚动 | 动画与当前区域的位置对应，章节增加新信息 | 视频自行播完、文字和画面错章 |
| 中段停止滚动 | 短暂收敛后稳定，能观察结构 | 继续自动播放、持续追赶抖动 |
| 连续向上回滚 | 回到正确结构状态和对应文案 | 只退字幕、产品不退、突然回首帧 |
| 快速往返 | 最后停在最新目标位置，无黑闪或失控 | 队列积压导致倒退、旧请求覆盖新状态 |
| 中段刷新、锚点进入、浏览器返回 | 恢复目标区域，不被入场动画重置 | 起始状态与实际滚动位置脱节 |
| 滚出主视觉 | 顺畅进入介绍、规格和有效下一步 | 只剩一个演示Hero、大片空白 |
| 切换款式/口味 | 素材、文字、选中状态同步；位置合理 | 只换标签、图片不变、点击无效 |
| 桌面与窄屏 | 无遮挡、按钮可操作，主体关键部分可见 | 只缩小桌面图、标题越界、主体被裁没 |
| 减少动态效果 | 稳定画面和完整内容仍可访问 | 必须播放动画才看得到介绍 |
| 缺媒体/加载失败 | 有清楚退路，主内容仍可阅读 | 空白屏、永久loading、无尽重试 |

## 最小证据

保留一段连续的“进入—下滚—停住—上滚—离开Hero—选择款式”操作记录，或在工具不支持录制时记录实际连续操作与逐项观察。补充桌面/窄屏关键截图。报告浏览器、视口、资源错误与未覆盖的设备；不要由桌面模拟推断所有手机都已验证。

视觉检查与技术检查分别记录。可以编译不等于观感流畅；抽帧能判断某些构图，不能证明全过程连续。长篇介绍还应检查每个章节有没有新增信息、读得完的文字和有效操作。
